Huawei Cloud configuration checklist

  1. Verify ecs-web serves this UI on TCP port 80.
  2. Unbind its EIP using the ECS console.
  3. Create elb-web in vpc-primary and attach that EIP.
  4. Use listener TCP :80 with backend group server_group-web, weighted round robin, ECS backend port 80.
  5. Register at least two healthy application ECSs, then open this website through the ELB public EIP.
  6. Collect a screenshot of ELB backend health and this page’s node distribution. A single node does not prove an ELB failure.

Image and Auto Scaling group setup

  1. First confirm RDS, login and Docker autostart work on ecs-web. Avoid copying stale passwords or test evidence into an image distributed beyond class.
  2. Create image-web using Huawei Image Management Service (IMS).
  3. Create as-config-web using that image, security group sg-web, and no public EIP.
  4. Create as-group-web in vpc-primary/subnet-web, attach to the ELB backend port 80; use min 1, desired 2, max 5.
  5. Configure both CPU policies and wait for actual Cloud Eye monitoring windows. Start CPU load on an instance inside the AS group.
  6. Inspect the AS action log. A CPU load on the original standalone ECS does not prove the scaling policy works.

Mandatory cloud security exercises

01 · Restrict database access

Allow MySQL TCP 3306 only from the authorized web-server security group/private subnet, not 0.0.0.0/0. Verify a real RDS connection here.

02 · Verify public exposure

ECS/ELB should expose only intended app traffic; use a dedicated management path for SSH. Inspect SG inbound rules and EIP attachments in the console.

03 · Prove least privilege

Inspect IAM user access and the account used by the application. RDS credentials should not be reused as an administrator account after initial schema setup.

04 · Attack-surface protection

This classroom version deliberately has no application login. Lock down the Huawei ECS security group to training source IPs, and verify bounded stress tests, API rate limits and that no Docker socket is mounted.

05 · Data in transit

Test MySQL TLS here. Demonstrate the difference between lab HTTP port 80 and production HTTPS with properly managed certificates.

06 · Availability & incident evidence

Take screenshots of healthy ELB backends, AS action logs, notifications and Cloud Eye alarms.
